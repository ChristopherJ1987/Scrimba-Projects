# Scrimba Projects

This repository contains all projects completed through Scrimba's React course, focusing on modern React development and component-based architecture.

## React Projects

Interactive React applications demonstrating hooks, state management, API integration, and modern React patterns.

### Projects Included:

- **Meme-Generator** - Interactive meme creation app
  - React hooks (useState, useEffect)
  - API integration for fetching meme templates
  - Dynamic image and text overlay
  - Form handling and user input

- **Airbnb-Mockup** - Airbnb-style accommodation listing
  - Component composition and reusability
  - Props and data passing
  - Responsive design with React
  - Modern UI/UX patterns

- **Hello-React** - Introduction to React fundamentals
  - JSX syntax and React basics
  - Component structure and organization
  - React development environment setup
  - Foundation for React learning

## About This Repository
This consolidation contains all the Scrimba React course projects that were previously in separate repositories. Each project demonstrates progressive learning of React concepts and modern web development practices.

### Skills Demonstrated:
- **React Fundamentals** - Components, JSX, props, state
- **React Hooks** - useState, useEffect, custom hooks
- **API Integration** - Fetching and handling external data
- **Modern JavaScript** - ES6+, destructuring, arrow functions
- **Component Architecture** - Reusable and maintainable code structure
